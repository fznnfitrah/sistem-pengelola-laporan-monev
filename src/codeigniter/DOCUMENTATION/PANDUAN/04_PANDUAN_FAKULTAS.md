# PANDUAN PENGGUNA - ROLE FAKULTAS

## Overview

Role Fakultas berperan dalam:

- Melihat laporan dari semua program studi di fakultasnya
- Memonitor laporan monitoring dan evaluasi
- Mengakses dashboard fakultas

---

## 1. Login ke Sistem

1. Buka aplikasi di `http://localhost:8080`
2. Masukkan username dan password role Fakultas
3. Klik tombol **Login**
4. Anda akan diarahkan ke halaman Dashboard Fakultas

---

## 2. Dashboard Fakultas

**Akses:** Menu → **Dashboard Fakultas** atau halaman utama setelah login

Di dashboard ini Anda dapat melihat:

- **Ringkasan Laporan**: Status pengumpulan laporan dari prodi
- **Statistik**: Jumlah prodi, laporan masuk, laporan pending
- **Grafik & Chart**: Visualisasi data monev dan kinerja dari prodi di fakultas Anda
- **Aktivitas Terbaru**: Laporan terbaru yang masuk

---

## 3. Melihat Laporan Prodi

### 3.1 Menu Laporan

**Akses:** Menu → **Laporan**

Di halaman ini Anda dapat melihat semua laporan dari prodi-prodi yang ada di fakultas Anda.

### 3.2 Filter & Cari Laporan

- **Filter Periode**: Pilih periode akademik tertentu
- **Filter Prodi**: Pilih prodi untuk melihat laporan spesifik
- **Cari**: Gunakan fitur cari untuk menemukan laporan

### 3.3 Melihat Detail Laporan

1. Klik pada laporan yang ingin dilihat detail-nya
2. Anda akan melihat:
   - **Data Umum**: Program studi, periode, tanggal pengumpulan
   - **Data Monev**: Nilai-nilai monitoring dan evaluasi
   - **Bukti Pendukung**: Link ke bukti atau dokumen pendukung
   - **Keterangan**: Catatan atau penjelasan dari prodi

### 3.4 Download Laporan

- Klik tombol **Download** atau **Export** untuk mengunduh laporan dalam format PDF atau Excel
- Gunakan laporan ini untuk presentasi atau dokumentasi

---

## 4. Monitoring Laporan

**Akses:** Menu → **Monitoring** atau **Monitoring Laporan**

### 4.1 Status Pengumpulan Laporan

Di halaman ini Anda dapat melihat:

- **Status Lengkap**: Laporan mana saja yang sudah dikumpulkan dari setiap prodi
- **Status Pending**: Laporan yang belum dikumpulkan
- **Presentase Pengumpulan**: Persentase laporan yang sudah dikumpulkan

### 4.2 Filter & Analisa

- **Filter Periode**: Lihat status pengumpulan per periode
- **Filter Prodi**: Lihat status per prodi
- **Reminder**: Sistem dapat mengirim reminder ke prodi tentang laporan yang belum dikumpulkan

---

## 5. Profil Pengguna

**Akses:** Menu → **Profil** atau klik nama pengguna di pojok kanan atas

Di halaman ini Anda dapat:

- **Mengubah Data Profil**: Ubah nama, email, nomor telepon
- **Ganti Password**: Ubah password akun
- **Lihat Informasi Akun**: Lihat detail akun Anda

---

## 6. Menu Navigasi Fakultas

| Menu                   | Fungsi                   |
| ---------------------- | ------------------------ |
| **Dashboard Fakultas** | Halaman utama/beranda    |
| **Laporan**            | Melihat laporan prodi    |
| **Monitoring**         | Memonitor status laporan |
| **Profil**             | Ubah profil pengguna     |
| **Logout**             | Keluar dari sistem       |

---

## 7. Tips & Tricks

- **Analisa Data**: Gunakan fitur filter untuk menganalisa data per prodi
- **Download Laporan**: Download laporan secara berkala untuk dokumentasi
- **Pantau Deadline**: Perhatikan deadline pengumpulan laporan
- **Hubungi Prodi**: Jika ada laporan yang pending, hubungi prodi untuk follow-up
