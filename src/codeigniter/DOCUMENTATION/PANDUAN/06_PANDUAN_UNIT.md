# PANDUAN PENGGUNA - ROLE UNIT

## Overview

Role Unit (Unit Kerja/Lembaga Unit) berperan dalam:

- Mengisi laporan monitoring dan evaluasi unit
- Menginput data kinerja unit
- Melihat riwayat laporan yang sudah dikumpulkan

---

## 1. Login ke Sistem

1. Buka aplikasi di `http://localhost:8080`
2. Masukkan username dan password role Unit
3. Klik tombol **Login**
4. Anda akan diarahkan ke halaman Dashboard Unit

---

## 2. Dashboard Unit

Halaman utama dengan ringkasan:

- **Status Laporan**: Laporan mana saja yang sudah diisi
- **Deadline**: Deadline pengumpulan laporan
- **Reminder**: Notifikasi laporan yang perlu diisi

---

## 3. Mengisi Laporan Monitoring dan Evaluasi

### 3.1 Input Laporan Monev Unit

**Akses:** Menu → **Laporan** → **Input Laporan** atau **Laporan Baru**

#### Langkah-langkah Input:

1. Klik tombol **+ Input Laporan** atau **Laporan Baru**
2. Pilih **Periode Akademik**: Pilih periode yang aktif
3. Isi **Data Unit**:
   - Nama unit akan otomatis terisi
   - Unit otomatis terisi sesuai login Anda
4. Isi **Parameter Monev Unit**:
   - Untuk setiap parameter monev yang ada, masukkan nilai yang sesuai
   - Nilai dapat berupa angka, persentase, atau deskripsi
   - Contoh parameter: Tingkat Kepuasan, Produktivitas, Kinerja Program, dst
5. **Link Bukti Pendukung**:
   - Masukkan link atau upload dokumen sebagai bukti
   - Bisa berupa link Google Drive, dokumen PDF, laporan, atau file lainnya
6. **Keterangan**:
   - Tambahkan catatan atau penjelasan jika diperlukan
7. Klik **Simpan** atau **Kirim**

### 3.2 Melihat Riwayat Laporan

**Akses:** Menu → **Laporan** → **Riwayat Laporan** atau **History**

Di halaman ini Anda dapat melihat:

- **Daftar Laporan**: Semua laporan yang sudah dikumpulkan
- **Status**: Status pengiriman laporan
- **Tanggal**: Tanggal pengumpulan laporan
- **Detail**: Klik untuk melihat detail laporan
- **Edit**: Jika belum deadline, Anda bisa mengedit laporan
- **Hapus**: Jika belum deadline, Anda bisa menghapus laporan

### 3.3 Edit Laporan

1. Di halaman Riwayat, cari laporan yang ingin diedit
2. Klik tombol **Edit** atau ikon pensil
3. Ubah data yang diperlukan
4. Klik **Simpan** atau **Update**

---

## 4. Menginput Data Kinerja Unit

### 4.1 Input Kinerja Unit

**Akses:** Menu → **Kinerja** → **Input Kinerja**

#### Langkah-langkah Input:

1. Klik tombol **+ Input Kinerja** atau **Kinerja Baru**
2. Pilih **Periode Akademik**: Pilih periode yang aktif
3. Isi **Parameter Kinerja Unit**:
   - Untuk setiap parameter kinerja, masukkan nilai yang sesuai
   - Contoh: Tingkat Penyelesaian Tugas, Efisiensi Biaya, Kepuasan Pelanggan, Inovasi Program, dst
4. **Target**:
   - Masukkan target yang ingin dicapai (jika ada)
5. **Bukti Pendukung**:
   - Masukkan link atau upload dokumen sebagai bukti
6. **Keterangan**:
   - Tambahkan catatan jika diperlukan
7. Klik **Simpan** atau **Kirim**

---

## 5. Profil Pengguna

**Akses:** Menu → **Profil** atau klik nama pengguna di pojok kanan atas

Di halaman ini Anda dapat:

- **Mengubah Data Profil**: Ubah nama, email, nomor telepon
- **Ganti Password**: Ubah password akun
- **Lihat Informasi Akun**: Lihat detail akun Anda

---

## 6. Menu Navigasi Unit

| Menu          | Fungsi                           |
| ------------- | -------------------------------- |
| **Dashboard** | Halaman utama/beranda            |
| **Laporan**   | Input & lihat laporan monev unit |
| **Kinerja**   | Input data kinerja unit          |

---

## 7. Tips & Tricks untuk Unit

- **Perhatikan Deadline**: Selalu perhatikan deadline pengumpulan laporan
- **Siapkan Dokumen**: Siapkan dokumen pendukung sebelum input laporan
- **Update Berkala**: Update data secara berkala agar selalu up-to-date
- **Hubungi Universitas**: Jika ada parameter yang tidak jelas, hubungi universitas
- **Kontak Admin**: Jika ada kendala teknis, hubungi administrator sistem

---

## 8. Troubleshooting

### Problem: Tidak bisa input laporan

**Solusi:**

- Pastikan periode akademik aktif sudah diatur oleh universitas
- Cek apakah Anda sudah melewati deadline pengumpulan

### Problem: File tidak bisa di-upload

**Solusi:**

- Pastikan ukuran file tidak melebihi batas maksimal (biasanya 5-10 MB)
- Gunakan format file yang didukung (PDF, DOC, XLS, JPG, PNG)
- Gunakan link eksternal jika file terlalu besar

### Problem: Data tidak tersimpan

**Solusi:**

- Pastikan semua field yang wajib sudah diisi
- Cek koneksi internet Anda
- Refresh halaman dan coba lagi

---

**Pertanyaan atau masalah? Hubungi administrator sistem Anda.**
